# M3allem

M3allem ("teacher") is an open-source learning project focused on making
educational tools more accessible.

> Early-stage project. Actively being built and documented.

## Goal
Make it easier for learners and teachers to access simple, free, open
educational tools, especially for people with limited resources.

## Status
Work in progress. The codebase, documentation, and onboarding guides are
being improved step by step. Contributions and feedback are welcome.
